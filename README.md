# Unsere Reise

Ein persönlicher Schwangerschaftsbegleiter: Wochenverlauf, Tagebuch mit
Wachstumskurve, Nahrungsergänzung, Warnzeichen, Sport- und Beckenbodenprogramm,
Anschaffungsplan und mehr.

Alle fachlichen Aussagen sind mit Quellen belegt (DGE, BfR, RKI, STIKO/BZgA,
ACOG, Embryotox, G-BA und weitere) und im Bereich "Alle Quellen" verlinkt.

Die App ersetzt keine individuelle Beratung durch Frauenärztin oder Hebamme.

## Technik

Eine einzelne `index.html`, keine Abhängigkeiten, kein Build-Schritt.
Alle Eingaben (Tagebuch, Fotos, Checklisten, Termin) bleiben im Browser
des jeweiligen Geräts – es werden keine Daten übertragen oder gespeichert.
